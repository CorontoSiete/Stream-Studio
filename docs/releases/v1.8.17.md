# Stream Studio 1.8.17

This release improves stream previews, keeps more browsing preferences between visits, and makes playback and navigation more reliable on Windows and in the LAN browser.

## Desktop

- **Discover language.** The app remembers the language selected on the Categories page. Categories without a saved language start with that selection.
- **Following artwork.** The home page reuses profile avatars and offline banners across refreshes, cutting repeat image downloads.

## LAN browser

- **Stream card previews.** Twitch and Kick cards use a direct HLS preview when the provider offers a compatible stream. Apple mobile browsers use native HLS playback.
- **Discover and search.** The browser remembers the Categories language in your account, runs a submitted channel search immediately, and lets you retry unavailable category suggestions.

## Improvements and bug fixes

- **Browsing.** Failed refreshes preserve the current cards and their next page. A late result can no longer replace a newer selection.
- **Playback and replay.** Live broadcast histories refresh while players are visible and catch up when you return. The theater controls stay in sync across players and reloads.
- **Volume and downloads.** Volume changes survive a player reload, saved volumes match channel names regardless of capitalization, and downloads recovered by a background refresh get their download controls.
- **Chat.** Twitch chat reconnects more reliably, and the desktop handles repeated animated images more efficiently.

## Updating

Open **Settings > Advanced > Updates** to download this release, then choose **Restart and install**. For a first installation, download `StreamlinkVlcStudio-Setup.exe` from the GitHub release.

Setup installations on 1.7.1 or earlier and ZIP installations on 1.8.6 or earlier need one manual upgrade to enable in-app updates. The GitHub release includes a signed update manifest and SHA-256 checksums.
