# Stream Studio 1.8.12

This release adds automatic downloads for completed broadcasts, full live history and seek previews in the browser player, and faster loading with a smaller installed footprint.

## New features

- **Automatic VOD downloads.** Right-click a Twitch or Kick VOD to enable automatic downloads for that channel. Stream Studio checks every two minutes while open, waits for broadcasts to finish, and uses your saved download settings. Older completed broadcasts are skipped.
- **Automatic download statistics.** Settings > Downloads lists enabled channels, completed download counts, and the space used by saved automatic downloads. Counts remain saved when media is deleted or a channel is disabled.
- **Full live history in the browser.** Rewind Twitch and Kick live broadcasts through their available archive, follow growing broadcast history, and return to the live stream while preserving pause state.
- **Browser seek previews.** Hover or scrub the seekbar to see the target time and a decoded video preview, including earlier live broadcast history. Playback position and audio stay unchanged while previewing.

## Improvements and fixes

- **Faster loading and refreshes.** Improved loading responsiveness across browsing, search, followed channels, VOD history, the library, and downloads. Refreshes preserve existing cards and reduce unnecessary work.
- **More reliable playback and downloads.** Improved completed-broadcast detection, VOD identity and watch progress, live seek controls, preview frame freshness, and cancellation of queued provider requests.
- **Smaller installed footprint.** Runtime libraries load from the installation folder without creating a duplicate .NET extraction cache. Managed code loads directly from the application bundle, and developer reference documentation is omitted from the installation.
- **Updater compatibility.** Update and maintenance commands start before the desktop interface loads. Signed release metadata retains the repository identity trusted by existing installations after the GitHub repository rename.

## Updating

Open **Settings > Advanced > Updates** to check for this release. Setup and owned ZIP installations can download a verified package and choose **Restart and install**. For a first installation, download `StreamlinkVlcStudio-Setup.exe` from this release.

If you are upgrading from 1.7.1 or earlier, run Setup manually once to enable the repaired in-app updater. ZIP installations of 1.8.6 or earlier also need one manual upgrade before they can use in-app ZIP updates. This release includes a signed update manifest and SHA-256 checksums.
