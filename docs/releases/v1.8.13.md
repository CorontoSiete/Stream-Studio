# Stream Studio 1.8.13

This release refreshes the LAN browser interface, makes Twitch and Kick channels easier to find and follow, and improves VOD downloads and chat overlays.

## New features

- **Refreshed LAN browser interface.** The sign-in screen, navigation, library, and preferences have been updated for desktop and mobile browsers. The sidebar can collapse, and player controls hide when idle.
- **Browser shortcuts follow the desktop app.** Browser accounts can override individual shortcuts for navigation, stream selection, playback, replay seeking, and volume. Skip distances and volume steps can be adjusted in browser preferences.
- **Optional LAN server startup.** After starting the server once, you can have Stream Studio reopen it on the saved network address and HTTPS port when the app starts.
- **Pin offline channels.** Keep favorite offline channels near the top of Following. Pins sync between the desktop app and the browser interface.

## Improvements and fixes

- **Channel search and discovery.** Search results include offline channels and show more available channel details. The browser lets you choose the discovery platform and filter streams by language where supported.
- **Twitch and Kick follows.** The desktop app reads Twitch follow status from the connected account and checks that the browser sign-in matches before changing a follow. Kick follow detection can import in the background using the saved website session, with a separate option to manage that sign-in.
- **VOD downloads.** MP4 is the default when no format preference has been saved. Automatic downloads continue checking later pages when a page is empty or contains unrelated videos.
- **Playback and chat.** Browser live-archive timing uses the playlist selected for playback. Desktop chat has clearer text and spacing, and the overlay clears its hover state when the pointer leaves the video.

## Updating

Open **Settings > Advanced > Updates** to check for this release. Setup and owned ZIP installations can download the verified update and choose **Restart and install**. For a first installation, download `StreamlinkVlcStudio-Setup.exe` from the GitHub release.
