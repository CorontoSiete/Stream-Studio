# Stream Studio 1.8.15

This release updates the Windows layout and makes playback controls, live replay, and navigation more reliable in the LAN browser.

## Desktop

- **Following and discovery.** The home layout separates browsing from your library and makes live and offline followed channels easier to find.
- **Playback controls and chat.** The desktop player updates its playback toolbar and docked chat layout, with clearer labels for key controls.
- **Application structure.** The desktop workspace and LAN browser assets now have their own projects, making it easier to maintain each interface.

## LAN browser

- **Mobile fullscreen.** Tap the fullscreen button or double-tap the video to enter fullscreen. On iPhone, **Fullscreen video** opens the selected stream in the native player.
- **Live replay.** Seeking follows the available replay range, and playback continues while the browser waits for an archive to become available.
- **Navigation and player state.** Changing pages cancels obsolete requests. Playback and sign-out actions handle slow responses without carrying stale state into the next session.

## Updating

Open **Settings > Advanced > Updates** to download this release, then choose **Restart and install**. For a first installation, download `StreamlinkVlcStudio-Setup.exe` from the GitHub release.

Setup installations on 1.7.1 or earlier and ZIP installations on 1.8.6 or earlier need one manual upgrade to enable in-app updates. The GitHub release includes a signed update manifest and SHA-256 checksums.
